A canvas that assembles itself

Components are brought onto the canvas as the conversation demands, wired to each other, and removed when they stop being relevant. Selecting a table in the tree retargets the grid — that is a declarative binding, not glue code.

The "model" here is a lookup table. Everything below it is real: the resolver picks components by scoring affordances, the wiring engine propagates in topological order, and every change is a patch appended to a document you can watch build up on the right.
