Color a query

colorQuery(text) reads the text with a parser generated from the apps' grammar, and says which ranges are keywords, keys, operators, values and variables. A word is colored as the API reads it: in after a key is an operator, and the in of meeting in march is plain text. It never reports an error. FacetSearch colors its syntax: "query" text with it.
