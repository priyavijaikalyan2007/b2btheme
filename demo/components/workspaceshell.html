WorkspaceShell

Chrome for the workspace tier — canvas tabs with pinning, a new-canvas control, a content region the canvas mounts into, and a history scrubber. Presentation only: every control emits and the host decides.

The hatched area is the content region — a real DynamicCanvas mounts there. This page leaves it empty on purpose so the chrome is the subject. Try the tabs, the pin stars, close, +, and the history scrubber along the bottom; every action is reported below.

Not to be confused with TenantSwitcher, which switches tenants. This switches canvases within one workspace.
