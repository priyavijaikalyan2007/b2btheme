Auth Card

The canonical login-card surface: brand header, identity-provider buttons, divider, and footer link. This markup and CSS are a frozen parity contract — the Keycloak FreeMarker fallback login on auth.knobby.io mirrors the exact same class structure so both logins are visually identical in light and dark mode (see specs/keycloak-theme-parity-requirements.md). Toggle the theme above: every color flips via --bs-* tokens.
