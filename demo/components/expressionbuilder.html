Build a query

Add conditions, words and groups, and join a group by all or any. On a relationship key, choose "the same item as" another condition, "has one where" for a search inside, or Link for conditions on the link. Drag a row by its grip, or use its buttons, or Alt with an arrow key. The API decides what a query means, so this page has no Parse or Print call. It shows the tree the builder reports.
