Thumbs, then Submit

Pick, change your mind, add a comment, then press Submit. onFeedback is called once, and the control locks only when the save resolves. This save takes a second.

Stars, sent on the first pick

commit: "once" with a 5-star scale and a summary. Arrow keys move between the stars; Space or Enter picks.

A save that fails

The first save rejects. The error shows in place, the pick and the comment stay, and Submit tries again.

A stored rating

initial shows a rating given before, saved and locked. reset() unlocks it.

Fluent UI icons

Every icon takes a Bootstrap Icons name or a full class, here Fluent UI's thumbs, flag and copy icons.

As a dialog

showFeedbackDialog asks for a 10-star rating and a comment, saved together in one call.
